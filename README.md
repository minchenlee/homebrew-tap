# homebrew-tap

Homebrew tap for minchenlee's apps.

## Install

```sh
brew install --cask minchenlee/tap/c9watch
```

Or tap first:

```sh
brew tap minchenlee/tap
brew install --cask c9watch
```

## Casks

| Cask | Description |
| --- | --- |
| [c9watch](https://c9watch.mclee.dev) | Dashboard for Claude Code and Codex sessions running on your machine |
